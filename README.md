# Dungeon Mart · 던전 속 편의점

중앙 마트를 운영하며 최대 20명의 용사에게 장비를 만들어 주는 픽셀 아트 자동 사냥 RPG입니다. 캐릭터·몬스터·건물·지형·UI 아이콘을 직접 그린 픽셀 그래픽으로 구성했습니다.

## 실행

Node.js 22 이상에서, 추가 패키지 설치 없이 실행합니다.

```sh
cd /Users/nykim/Code/00.Project/DungeonMart
npm start
```

브라우저에서 **http://localhost:4173** 에 접속하세요.

다른 에이전트가 이어받을 때는 **HANDOFF.md → docs/MAP_DESIGN.md** 순서로 읽으세요. 완료할 때마다 인계 노트를 갱신하는 규칙은 AGENTS.md에 있습니다. `index.html`을 직접 더블클릭하는 대신 로컬 서버를 사용해야 합니다. 포트를 바꾸려면 `PORT=4174 npm start`를 실행합니다. 저장은 브라우저와 접속 주소별로 구분됩니다.

## 첫 플레이

1. 기본 화면은 확대된 마트 주변입니다. 휠·핀치로 확대/축소하고 드래그로 이동하세요. **전체 지도**를 누르면 마트와 4개 액트를 한눈에 봅니다.
2. 다섯 용사는 자동으로 ACT I에 출발합니다. 1× / 2× / 4×는 카메라 배율이 아닌 게임 진행 속도입니다.
3. 하단 **용사** 메뉴에서 용사를 누르면 팝업이 열립니다. **장비** 탭의 제작소에서 장비를 만드세요. 첫 제작을 위한 재료가 제공됩니다.
4. 창고의 장비를 용사 장비창 격자에 놓으면(**배치** 또는 드래그) 그 용사의 골드로 구매하며 즉시 효과가 납니다. 마트 운영금으로 매출이 들어옵니다.
5. 팝업의 **정보 · 외형** 탭에서 외형과 능력치 변화를 확인하세요. 색상 원은 전투 능력치와 무관한 코스튬입니다.
6. 용사 한 명이 Lv.8 / 20 / 35에 도달하면 다음 액트가 열립니다. 하단 **사냥터** 보드에서 용사 아이콘을 원하는 액트 열로 끌어다 놓으세요. **마을 대기** 열에 놓으면 사냥을 쉬고 마트에서 대기합니다.
7. Lv.20 / 40에 팝업의 **전직 · 스킬** 탭 트리에서 빛나는 계열 노드를 클릭하면 즉시 전직합니다. 스킬 포인트로 스킬을 강화할 수 있습니다.
8. **사냥터** 화면 위의 난이도 바에서 노멀 1~10단계를 고릅니다. 단계를 누르면 즉시 적용되고 5분 동안 고정됩니다. 그 난이도에서 보스를 잡으면 나이트메어, 다시 잡으면 헬이 열립니다. 나이트메어·헬 몬스터는 아직 임시 네모 박스로 표시됩니다.
9. 지도의 **보스 소환**(500 G)을 누르면 ACT IV 봉인문 앞에 재의 군주가 나타나고 모든 용사가 출격합니다. 4분 안에 처치하면 현상금 2,000 G와 영혼 결정을 받습니다.

## 구현 범위

- 3,600×2,800 월드에 중앙 마트와 4개 독립 액트. 사이의 협곡과 다리로 지역 구분.
- 휠·핀치 확대/축소, 드래그, 미니맵, 액트 바로가기, 헌터 추적, 지도 넓게 보기.
- 남쪽 헌터 도착장 → 등록 → 마트로 이어지는 실제 입장 동선.
- 공방·물류·훈련장 및 액트별 기믹의 확장 지점과 설명 상호작용.
- 액트별 대표 몬스터 4종씩, 총 16종. 부활, 전격 반격, 독, 약화, 소환 등 행동 구분.
- 바바리안, 네크로맨서, 아마존, 소서리스, 팔라딘. 5명으로 시작, 최대 20명 영입.
- 자동 이동·전투·스킬·재료 수집·귀환·회복·부활. 공동 전투 시 보상 분배, 회복·보호 지원 기여.
- 각 기본 직업 → 2개 2차 → 각각 2개 3차. 최종 직업 20개.
- 1차 액티브 2개 → 2차 액티브 4개·패시브 1개 → 3차 액티브 6개·패시브 2개.
- 용사마다 크기가 다른 무기칸·방어구칸·장신구칸 격자 장비창. 장비를 놓는 순간 효과 적용, 손·부위 규칙과 무게 제한.
- 일반·매직·레어·세트·유니크 등급, 앞말/뒷말 접사, 홈에 보석·각인석 삽입, 각인석 조합으로 진언 완성. 직업 세트 5종, 유니크 24종.
- 몬스터 드롭 → 귀환 입고 → 마을 창고. 세트·유니크는 지도 빛기둥으로 떨어져 클릭 획득(5분 후 자동 입고).
- 대장간 제작(베이스·등급·단계 선택), 첫 배치 시 구매, 용사 간 무료 이동, 분해, 조합(합성·홈 뚫기·재련·승급·단계 올리기). 제작대·회복·창고 시설 업그레이드.
- 장비와 연동된 무기·갑옷 외형, 능력치와 분리한 5개 외형 팔레트.
- 10초마다 브라우저 자동 저장, 저장 파일 내보내기·불러오기, 새 게임 확인.
- 데스크톱 및 좁은 화면 대응.

## 현재 프로토타입 규칙과 제한

- 외형은 Canvas로 직접 그린 픽셀 아트입니다. 용사는 24×32 픽셀 레이어를 합성하고, 월드는 1 픽셀 = 1 월드 단위 버퍼에 현재 카메라에 보이는 부분을 합성한 뒤 보간 없이 확대합니다(축소 시에만 스무딩). 건물·나무 등 소품은 Scale2x로 업스케일해 발자국을 유지합니다. 디아블로 II 원본 이미지나 모델을 포함하지 않습니다.
- 전직별 스킬은 실제 효과를 가지지만, 관통·화염 지대·궁극기 일부는 범위 피해와 상태 효과로 단순화했습니다. 스킬 설명의 핵심 역할을 먼저 검증하는 단계입니다.
- 무기·보조 장비는 베이스별 직업 제한이 있고 2단·3단 베이스는 Lv.25·45가 필요합니다. 바바리안만 한손 무기 쌍수가 가능합니다.
- 스킬 포인트 초기화는 무료입니다. 전직 계열 자체의 변경과 스킬별 세부 룬 선택은 아직 없습니다.
- 체력 28% 미만 또는 처치 기여 12회 후 자동 귀환합니다. 전리품은 귀환 시 공용 창고에 입고됩니다.
- 회복은 무료, 사망 시 장비·경험치 손실 없이 10초 부활 대기. 귀환 중에는 전투 대상에서 제외됩니다.
- 레벨 상한 60, 스킬 레벨 상한 5, 시설 레벨 상한 5, 창고 용량 80~192칸(가득 차면 새 전리품은 자동 분해).
- 정예 몬스터는 지역 처치 누적에 따라 나타납니다. 보스는 소환형 레이드 한 종류(재의 군주 바라칸)이며, 디아블로 II의 액트 보스나 전체 몬스터 목록은 구현하지 않았습니다.
- 브라우저 탭을 숨기거나 닫으면 시뮬레이션은 멈추지만, 다시 열 때 최근 귀환 입고량으로 측정한 분당 수익률 × 60% × 경과 시간(최대 8시간)만큼 재료를 정산해 줍니다. 골드·경험치는 오프라인에 오르지 않습니다. 서버, 멀티플레이, 사운드는 없습니다.

## 파일 구조

- `src/data.js`: 직업·전직·스킬·액트·몬스터 데이터.
- `src/items.js`: 장비 베이스·접사·보석·각인석·진언·세트·유니크 데이터, 아이템 생성기, 격자 규칙.
- `src/engine.js`: DOM과 독립된 전투·경제·성장·장비창·드롭·조합·저장 상태 로직.
- `src/gear-ui.js`: 장비창·창고·서랍·제작·조합 화면과 드래그 앤 드롭.
- `src/world.js`: 지역·연결로·입구·기믹 배치와 충돌 데이터.
- `src/camera.js`: 좌표 변환, 줌, 화면 경계.
- `src/navigation.js`: A* 길찾기와 이동.
- `src/map-input.js`: 마우스·터치 지도 조작.
- `src/world-art.js`: 지형·다리·기믹·장식 픽셀 렌더링.
- `src/render.js`: 카메라 영역 합성, 미니맵, 장비 외형 해석.
- `src/pixel-art.js`: 용사·몬스터·나무·돌·마트의 픽셀 스프라이트, 레이어별 색상·장비 합성.
- `src/pixel-icons.js`: 12×12 격자의 UI 아이콘.
- `src/app.js`: 화면·입력·게임 루프·브라우저 저장.
- `style.css`: 반응형 관리 화면 스타일.
- `docs/DESIGN.md`: 첫 버전의 규칙과 코스튬 확장 설계.
- `docs/EQUIPMENT_DESIGN.md`: 장비 시스템 v2 설계. 구현 상태와 차이는 HANDOFF.md 참고.
- `tests/engine.test.mjs`: 경제·성장·전투·저장 회귀 테스트.
- `tests/items.test.mjs`: 장비 데이터 정합성, 생성기 분포, 격자·손 규칙, 무게, 홈·진언·조합, 빛기둥, 저장 검증.
- `tests/world.test.mjs`: 카메라·경로·입장·저장 마이그레이션 테스트.
- `tests/browser-smoke.mjs`: 선택 사항인 Chromium DevTools UI 테스트.

### 무작위 영입과 몬스터 젠

새 용사는 120 G로 영입하며 5개 직업이 각각 20% 확률로 등장합니다. 노멀/매직/레어/전설 확률은 60/25/12/3%, 기본 공격력·방어력·체력 배율은 1/1.2/1.45/1.8입니다. 등급은 이름 색상과 프로필에 표시합니다.

액트 카드를 선택하고 아래 `몬스터 젠`에서 1~5배를 설정하세요. 액트마다 독립적으로 저장하며, 재생성 대기시간만 줄입니다. 기본 간격은 1.8초, 5배는 0.36초이고 몬스터 정원에 도달하면 추가 생성하지 않습니다.

새 게임의 마트 운영금은 0 G에서 시작합니다. 용사에게 장비를 팔아(장비창 첫 배치) 운영금을 모아 영입과 시설 개선에 씁니다. 기존 저장 잔액은 유지합니다. 몬스터 젠은 액트 아래 1~5배 버튼으로 선택하며 생성 간격도 표시됩니다.
