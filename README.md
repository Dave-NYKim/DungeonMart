# Dungeon Mart · 던전 속 편의점

중앙 마트를 운영하며 최대 20명의 용사에게 장비를 만들어 주는 픽셀 아트 자동 사냥 RPG입니다. 캐릭터·몬스터·건물·지형·UI 아이콘을 직접 그린 픽셀 그래픽으로 구성했습니다.

## 실행

Node.js 22 이상에서, 추가 패키지 설치 없이 실행합니다.

```sh
cd /Users/nykim/Code/00.Project/DungeonMart
npm start
```

브라우저에서 **http://localhost:4173** 에 접속하세요.

다른 에이전트가 이어받을 때는 **HANDOFF.md → docs/MAP_DESIGN.md** 순서로 읽으세요. 완료할 때마다 인계 노트를 갱신하는 규칙은 AGENTS.md에 있습니다. `index.html`을 직접 더블클릭하는 대신 로컬 서버를 사용해야 합니다. 포트를 바꾸려면 `PORT=4174 npm start`를 실행합니다. 저장은 브라우저와 접속 주소별로 구분됩니다.

## 첫 플레이

1. 이 게임은 핸드폰 세로 화면 기준으로 만듭니다. 기본 화면은 확대된 마트 주변입니다. 핀치(데스크톱은 휠)로 확대/축소하고 끌어서 이동하세요. **전체 지도**를 누르면 마트와 4개 액트를 한눈에 봅니다.
2. 다섯 용사는 자동으로 ACT I에 출발합니다. 게임 진행은 기본 2배속입니다.
3. 하단 **용사** 메뉴에서 용사를 누르면 팝업이 열립니다. **마을 → 제작소**에서 장비를 만드세요. 첫 제작을 위한 재료가 제공됩니다.
4. 창고의 장비를 용사 장비창 격자에 놓으면(**배치** 또는 드래그) 그 용사의 골드로 구매하며 즉시 효과가 납니다. 마트 운영금으로 매출이 들어옵니다.
5. 팝업의 **정보 · 외형** 탭에서 외형과 능력치 변화를 확인하세요. 색상 원은 전투 능력치와 무관한 코스튬입니다.
6. ACT 1~3 보스를 순서대로 처치하면 다음 액트가 열립니다. 하단 **사냥터** 보드에서 용사 아이콘을 원하는 액트 열로 끌어다 놓으세요. **마을 대기** 열에 놓으면 사냥을 쉬고 마트에서 대기합니다.
7. Lv.20 / 40에 팝업의 **전직 · 스킬** 탭 트리에서 빛나는 계열 노드를 클릭하면 즉시 전직합니다. 스킬 포인트로 스킬을 강화할 수 있습니다.
8. **사냥터**에서 액트 보스에 도전하거나 지도에서 액트 건물을 누르세요. 지하묘지·왕릉·덩굴 사원·용암문에 전용 보스가 있으며, 오아시스에서는 선택한 용사가 무료 회복을 위해 이동합니다.
9. ACT 4 보스를 처치하면 **최종보스 소환**(500 G)이 열립니다. 마을 북쪽 **종말의 봉인진**에 재의 군주가 나타나고 모든 살아 있는 용사가 현재 위치에서 출전합니다. 영혼은 회복소에서 부활 후 합류합니다. 제한 시간은 4게임분입니다.
10. **최종보스 처치 → 다음 난이도 단계 해금**입니다. 노멀 10단계 최종보스 후 나이트메어 1단계, 나이트메어 10단계 후 헬 1단계가 열립니다. 액트 보스 처치 기록은 난이도·단계별로 저장하며 새 단계는 액트 1부터 시작합니다.


모든 조작은 터치만으로 가능해야 합니다. 터치 UI 규칙과 현재 미비 항목은 [docs/MOBILE_UI.md](docs/MOBILE_UI.md)에 있습니다.

## 구현 범위

- 3,600×2,800 월드에 중앙 마트와 4개 독립 액트. 사이의 협곡과 다리로 지역 구분.
- 휠·핀치 확대/축소, 드래그, 미니맵, 액트 바로가기, 헌터 추적, 지도 넓게 보기.
- 남쪽 헌터 도착장 → 등록 → 마트로 이어지는 실제 입장 동선.
- 공방·물류·훈련장 및 액트별 기믹의 확장 지점과 설명 상호작용.
- 액트별 대표 몬스터 4종씩, 총 16종. 부활, 전격 반격, 독, 약화, 소환 등 행동 구분.
- 바바리안, 네크로맨서, 아마존, 소서리스, 팔라딘. 5명으로 시작, 최대 20명 영입.
- 자동 이동·전투·스킬·재료 수집·귀환·회복·부활. 공동 전투 시 보상 분배, 회복·보호 지원 기여.
- 각 기본 직업 → 2개 2차 → 각각 2개 3차. 최종 직업 20개.
- 1차 액티브 2개 → 2차 액티브 4개·패시브 1개 → 3차 액티브 6개·패시브 2개.
- 용사마다 크기가 다른 무기칸·방어구칸·장신구칸 격자 장비창. 장비를 놓는 순간 효과 적용, 손·부위 규칙과 무게 제한.
- 일반·매직·레어·세트·유니크 등급, 앞말/뒷말 접사, 홈에 보석·각인석 삽입, 각인석 조합으로 진언 완성. 직업 세트 5종, 유니크 24종.
- 몬스터 드롭 → 귀환 입고 → 마을 창고. 세트·유니크는 지도 빛기둥으로 떨어져 클릭 획득(5분 후 자동 입고).
- 하단 **마을** 메뉴는 마을 창고를 보여주고 **마을 편집** 버튼으로 시설 이동·장식 배치 모드에 들어갑니다.
- **마을 → 제작소**에서 제작(베이스·단계 선택, 일반 60%·매직 30%·레어 10% 무작위 등급과 옵션), 창고 정리, 등급별 전체 분해, 세트·유니크 분해로 유물의 정수 획득, 조합(합성·홈 뚫기·재련·승급·단계 올리기), 시설 업그레이드. 장비 배치는 용사 팝업의 장비 탭.
- 운영금은 장비 최초 판매와 보스 현상금으로 획득합니다. 노멀 액트 보스25/40/55/70G, 최종보스200G(나이트3배·헬8배). 최종보스 참여 용사는 별도 개인 골드도 획득합니다(노멀1단계162G/명). 장비 목록/상세에 판매가 또는 구매 완료를 표시합니다.
- 보스 소환은 운영금 500 G, 게임 시간 20분에 한 번. 장비는 세트·유니크만 빛기둥으로 드롭한다. 기본 합산 확률은 일반 몬스터 0.003%, 정예 0.15%, 보스 2.5%이며 첫 처치·천장 보장은 없다. 보석·각인석·재료 획득은 유지한다.
- 장비와 연동된 무기·갑옷 외형, 능력치와 분리한 5개 외형 팔레트.
- 10초마다 브라우저 자동 저장, 저장 파일 내보내기·불러오기, 새 게임 확인.
- 데스크톱 및 좁은 화면 대응.

## 현재 프로토타입 규칙과 제한

- 용사·몬스터·주요 건물은 생성한 픽셀 원본을 로컬 자산으로 보관하고 Canvas에 표시합니다. 월드는 1 픽셀 = 1 월드 단위 버퍼에 현재 카메라에 보이는 부분을 합성한 뒤 보간 없이 확대합니다(축소 시에만 스무딩). 건물·나무 등 소품은 Scale2x로 업스케일해 발자국을 유지합니다.
- 전직별 스킬은 실제 효과를 가지지만, 관통·화염 지대·궁극기 일부는 범위 피해와 상태 효과로 단순화했습니다. 스킬 설명의 핵심 역할을 먼저 검증하는 단계입니다.
- 무기·보조 장비는 베이스별 직업 제한이 있고 2단·3단 베이스는 Lv.25·45가 필요합니다. 바바리안만 한손 무기 쌍수가 가능합니다.
- 스킬 포인트 초기화는 무료입니다. 전직 계열 자체의 변경과 스킬별 세부 룬 선택은 아직 없습니다.
- 체력 28% 미만 또는 처치 기여 12회 후 자동 귀환합니다. 전리품은 귀환 시 공용 창고에 입고됩니다.
- 회복은 무료, 사망 시 장비·경험치 손실 없이 영혼으로 회복소에 이동하고, 도착 후 12초 대기 뒤 부활. 귀환 중에는 전투 대상에서 제외됩니다.
- 모든 용사의 최대 레벨은 전직과 관계없이 Lv.100입니다. Lv.10까지 기존 성장 속도를 유지하고 이후 경험치 요구량이 급증하며, Lv.40부터 더욱 가파르게 증가합니다. 레벨당 능력치 증가량은 기존과 같습니다. 다음 단계 ACT1은 이전 단계 ACT4보다 강합니다. 스킬 레벨 상한 5, 시설 레벨 상한 5, 창고 용량 80~192개(장비 크기와 관계없이 1개당 1자리). 세트·유니크는 가득 차면 낮은 등급 장비를 분해해 입고하며, 자리를 만들 수 없으면 빛기둥으로 남는다.
- 정예 몬스터는 지역 처치 누적에 따라 나타납니다. 액트별 보스 4종과 최종보스 재의 군주 바라칸이 있습니다.
- 브라우저 탭을 숨기거나 닫으면 시뮬레이션은 멈추지만, 다시 열 때 최근 귀환 입고량으로 측정한 분당 수익률 × 60% × 경과 시간(최대 8시간)만큼 재료를 정산해 줍니다. 골드·경험치는 오프라인에 오르지 않습니다. 서버, 멀티플레이, 사운드는 없습니다.

### 무작위 영입과 몬스터 젠

새 용사는 120 G로 영입하며 5개 직업이 각각 20% 확률로 등장합니다. 노멀/매직/레어/전설 확률은 60/25/12/3%, 기본 공격력·방어력·체력 배율은 1/1.2/1.45/1.8입니다. 등급은 이름 색상과 프로필에 표시합니다.

액트 카드를 선택하고 아래 `몬스터 젠`에서 1~5배를 설정하세요. 액트마다 독립적으로 저장하며, 재생성 대기시간만 줄입니다. 기본 간격은 1.8초, 5배는 0.36초이고 몬스터 정원에 도달하면 추가 생성하지 않습니다.

새 게임의 마트 운영금은 0 G에서 시작합니다. 용사에게 장비를 팔아(장비창 첫 배치) 운영금을 모아 영입과 시설 개선에 씁니다. 기존 저장 잔액은 유지합니다. 몬스터 젠은 액트 아래 1~5배 버튼으로 선택하며 생성 간격도 표시됩니다.

- **도감**의 몬스터·세트·유니크 탭: 세트 5종의 30부위와 동시 착용 효과, 유니크 24종의 옵션·획득 여부. 획득 기록은 분해 후에도 보존한다.

- 하단 메뉴는 맵·용사·사냥터·마을·도감·설정. 마을 안에서 창고 / 제작소 / 꾸미기를 전환한다. 소식 탭은 제거했다. 지도 확대·축소는 핀치 또는 마우스 휠로 조작한다.

- 난이도는 단계마다 몬스터·보스가 강해진다. 보스 능력치는 난이도/단계/용사 수로 정하며, 장비나 레벨을 올려도 함께 강해지지 않는다. 기존 저장의 몬스터도 남은 HP 비율을 보존해 새 기준으로 보정한다.
