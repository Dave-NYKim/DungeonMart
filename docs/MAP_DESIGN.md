# 연결형 대륙과 마을 편집

2026-09-11 구현 기준. 예전 원형 섬 4개와 협곡/다리 중심 설계는 폐기했다.

## 배치 원칙

사용자가 준 항구–마을–액트 IV / 액트 I–II–III는 상대 위치 참고다. 동일 크기 격자로 맞추지 않는다. 북쪽을 빈 가로줄로 남기지 않는다.

- 서쪽 해안에 여명 항구, 동쪽으로 마을이 이어진다.
- 액트 I 숲/황야가 남서쪽에서 북서쪽으로 길게 올라간다.
- 액트 II는 남부의 비교적 낮고 넓은 사막과 왕릉, III은 남동쪽의 습지와 밀림.
- IV는 동쪽에서 북동쪽으로 뻗은 화산 지대. 북중부는 산맥/숲 안에 일부 미개척 공간.
- 지형별 면적/경계가 다르고 픽셀 디더링으로 전환된다. 하천, 사구, 고사목, 묘지, 사원, 화산 균열로 구분한다.

## 좌표와 이동

WORLD 3600×2800, revision=3. regionAt은 연속 좌표에 따른 불규칙 경계, terrainBlocked는 물/산악/주요 하천/균열, solidAt은 현재 건물 위치를 사용한다. 장식 전체가 충돌체인 것은 아니다. 주도로의 하천 횡단부는 이동 가능하다.

용사 영입은 4초 입항 후 부두 하선, 등록소 1.5초, 마트 경유 순서. 입항 중은 arrivalStage=-1이며 물 위 좌표가 정상이다.

## 마을 편집

6개 시설 이동: 마트, 회복의 샘, 게시판, 대장간, 창고, 훈련장. 편집 경계 안에서 32 단위로 배치하고 주도로와 시설 사이 여유 공간을 확보한다. 마트 이동은 시뮬레이션의 귀환 지점도 바꾼다. navigation은 layoutRevision이 바뀌면 경로/그리드를 다시 만든다.

5개 장식: 돌길, 가로수, 화단, 벤치, 가로등. 무료이며 최대 300개. 미관용으로 길찾기 지형은 바꾸지 않는다. 즉시 저장, 세션 내 20회 되돌리기, 기본 배치 복원. 시설 새 구매/회전, 자율 도로 네트워크 시뮬레이션은 현재 범위에 없다.

## 저장

기존 version=2 유지. worldRevision=3, town={buildings,decorations}. 이전 좌표만 안전 위치로 옮기고 돈/재료/용사/레벨/전직/장비는 보존한다. 현재 상태의 applyTownLayout과 임시 저장 읽기를 구분한다.
