# 장비 시스템 설계 v2 · 2026-09-11

**상태: 설계 문서. 아직 구현하지 않았다.** 현재 코드(`src/data.js`의 `RARITIES` 4단계, `src/engine.js`의 `craft/equip/salvage`, 용사당 무기·방어구·액세서리 3슬롯)를 이 문서의 구조로 교체하는 것이 목표다. 구현 순서는 마지막 장 "구현 단계"를 따른다.

디아블로 II의 격자 인벤토리·접두사/접미사·소켓·룬워드·세트/유니크 구조의 **재미**를 가져오되, 명칭·아이템 이름·룬 이름·룬워드 이름·세트/유니크 이름·수치는 전부 자체 제작한다. 원작의 고유 명칭(El/Eld/Tir…, Enigma, Windforce, Tal Rasha 등)과 원작 아이콘은 사용하지 않는다.

---

## 1. 설계 목표

1. **템트리스**: 장비는 "장착" 버튼이 아니라 **용사 장비창의 격자에 놓는 순간** 효과가 발동한다. 칸이 곧 슬롯이다. 좋은 장비일수록 칸을 많이 차지하고, 남는 칸은 부적으로 채운다.
2. **무한 반복 플레이**: 등급 5종 × 접두사/접미사 조합 × 홈/각인석/진언 × 세트 수집 × 유니크 도감 × 심연 층 스케일링. 항상 "다음에 나올 수 있는 더 좋은 것"이 존재해야 한다.
3. **마트 경영과 연결**: 드롭·제작품은 마을 창고에 모이고, 주인이 용사에게 팔아서(장비창에 넣어서) 운영금을 번다. 재료 획득·판매가 상승 같은 경영형 옵션이 전투 옵션과 경쟁한다.
4. **저장 호환**: 기존 저장의 장비를 새 구조로 변환하고 능력치 손실을 만들지 않는다.

## 3. 아이템 데이터 구조

```js
// 생성된 아이템 인스턴스 (저장됨)
{
  id: 'i123',
  base: 'longsword',        // BASE_ITEMS 키
  tier: 1,                  // 기본 아이템 단계 1·2·3 (이름이 달라짐, 5장)
  grade: 'magic',           // normal | magic | rare | set | unique
  quality: 0,               // 일반 등급만: -1 조잡 / 0 보통 / +1 정교
  ilvl: 23,                 // 출처 레벨
  name: '예리한 늑대의 장검',   // 표시용 완성 이름 (생성 시 확정)
  nameParts: { prefix: 'keen', suffix: 'wolf', rare: null, fixed: null },
  affixes: [ { id: 'keen', tier: 2, stats: { atkPct: .12 } }, ... ],
  implicit: { atk: 14 },    // 베이스 고유 기본치(품질·단계 반영)
  sockets: 3,               // 홈 개수 (0이면 없음)
  inserts: ['rune:ar', 'gem:ruby:3', null],  // 홈에 박힌 박음돌, 순서 유지
  mantra: null,             // 완성된 진언 id (있으면 inserts 순서가 레시피와 일치)
  setId: null, uniqueId: null,
  weight: 8,                // 베이스 무게 (접사로 변동 가능)
  w: 1, h: 3, rotated: false,
  identified: true,         // 2단계 옵션: 미감정 드롭
  purchased: false,         // 첫 배치 시 용사 골드 → 운영금
  origin: { kind: 'drop', zone: 2, abyss: 0 } // drop | craft | recipe | merchant | migrate
}
```

능력치 계산 순서(`statsOf`):
`베이스 implicit` → `접사 합산` → `홈 박음돌 합산` → `진언 보너스` → `세트 보너스(장착 개수 기준)` → `유니크 고유 효과` → 용사 스킬 패시브. 모든 % 옵션은 같은 키끼리 덧셈 후 곱한다(`atkPct` 합계 → `atk × (1 + 합계)`).

새로 추가되는 능력치 키 (기존 `atk def hp crit haste leech spell petdamage cooldown` 유지):

| 키 | 표시 | 설명 |
|---|---|---|
| `atkPct` `defPct` `hpPct` | 공격력 % / 방어력 % / 체력 % | 곱연산 |
| `fire` `cold` `lightning` `poison` | 화염/냉기/번개/독 추가 피해 | 공격당 고정 추가 피해. 냉기는 둔화, 독은 지속 피해 |
| `resFire` `resCold` `resLightning` `resPoison` `resAll` | 속성 저항 | 액트 III·IV 및 심연에서 몬스터 속성 공격 도입 전제. 상한 75% |
| `dr` | 피해 감소 % | 상한 40% |
| `regen` | 초당 체력 재생 | |
| `move` | 이동 속도 % | 사냥터 왕복 시간에 영향 → 시간당 수익 |
| `str` | 힘 | 무게 용량 +1/점 |
| `gold` `matFind` `xp` | 골드 획득 / 재료 획득 / 경험치 % | 경영형 옵션 |
| `find` | 장비 발견 % | 상위 등급 확률 상승 (MF) |
| `price` | 마트 판매가 % | 이 용사가 사는 장비 가격 상승 = 운영금 증가 |
| `thorns` | 반사 피해 | |
| `carry` | 임시 가방 크기 % | 귀환 전 재료 보유량 |

## 4. 등급 5종

| 등급 | 색 | 접사 | 이름 규칙 | 홈 | 획득 |
|---|---|---|---|---|---|
| **일반** | 흰색 | 없음. 품질 조잡(-10%)/보통/정교(+15%) | `[품질] 베이스명` | 0~최대 (홈 있는 일반은 흰색 그대로) | 가장 흔함. **진언의 유일한 재료** |
| **매직** | 파랑 | 앞말 1 또는 뒷말 1 또는 둘 다 (1~2개) | `앞말 + 뒷말 + 베이스명` | 0~2 | 흔함 |
| **레어** | 노랑 | 3~6개 (앞말 최대 3, 뒷말 최대 3) | `[앞이름][뒷이름]` 2어절 무작위 + 베이스명 소표기 | 0~2 | 보통 |
| **세트** | 초록 | 고정 접사 + 세트 보너스 | 고정 (`세트명의 부위명`) | 0~1 (고정) | 드묾 |
| **유니크** | 황금 | 고정 접사(수치 ±10% 변동) + 고유 효과 1개 | 고정 | 0~2 (고정) | 매우 드묾 |

기존 `RARITIES` 4단계(일반/마법/희귀/전설)는 폐기하고 이 5단계로 교체한다. 용사 등급(`HERO_GRADES` 노멀/매직/레어/전설)은 별개 개념이므로 유지하되, 혼동을 피하려면 UI에서 용사 등급 표기를 "★/★★/★★★/★★★★"로 바꾸는 것을 권장한다.

**드롭 등급 확률(기본, `find` 0%)**

| 등급 | 일반 몬스터 | 정예 | 보스/심연 층 보상 |
|---|---|---|---|
| 일반 | 68% | 40% | 15% |
| 매직 | 24% | 38% | 40% |
| 레어 | 7% | 17% | 30% |
| 세트 | 0.7% | 3% | 8% |
| 유니크 | 0.3% | 2% | 7% |

`find` 1%마다 매직 이상 판정을 1% 높이고(체감 한계 300%), 세트·유니크 판정은 `find × 0.5`만 적용한다. 세트/유니크는 해당 ilvl에서 뽑을 수 있는 목록이 없으면 레어로 내려간다. 진언 재료용 **홈 있는 일반**은 일반 판정의 25%에서 나오며 홈 개수는 베이스 최대치 안에서 무작위.

## 6. 앞말 / 뒷말 (접두사 / 접미사)

한국어 어순에 맞춰 **앞말은 형용사형, 뒷말은 "○○의" 명사형**으로 두고, 표시는 `앞말 + 뒷말 + 베이스명` 순서다. 예: `예리한`(앞말) + `늑대의`(뒷말) + `장검` → **예리한 늑대의 장검**.

- 앞말: 공격·방어·속성·발견 같은 **전투/직접 효과**.
- 뒷말: 체력·힘·속도·저항·경영 같은 **자원/유틸 효과**.

## 9. 용사 장비창(격자)

### 9.1 구역

장비창은 **무기칸·방어구칸·장신구칸** 세 개의 독립 사각형 격자다. 아이템은 자기 종류의 구역에만 놓을 수 있다. 격자에 놓인 아이템은 조건(손 규칙·부위 규칙·직업·레벨·무게)을 만족하면 **즉시 활성**이며, 별도 장착 명령이 없다. 조건을 못 채우는 아이템은 회색 빗금으로 **비활성** 표시되어 자리는 차지하지만 효과가 없다.

세 구역의 칸 합계는 용사 등급으로 정해지고, 어떻게 나뉘는지는 영입 시 **직업 가중 무작위**로 정한다. 같은 직업이라도 무기칸이 큰 개체와 작은 개체가 있다.

**총 칸 수**

| 용사 등급 | 기본 합계 | 2차 전직 | 3차 전직 |
|---|---|---|---|
| 노멀 | 40 | +4 | +4 |
| 매직 | 44 | +4 | +4 |
| 레어 | 48 | +4 | +4 |
| 전설 | 54 | +4 | +4 |

전직 보너스 4칸은 2차에서 방어구칸 세로 +1줄(가로가 4일 때) 또는 장신구칸 +1열, 3차에서 나머지 하나에 준다. 프리셋의 가로·세로가 4/1을 만족하지 않으면 남는 칸은 장신구칸 확장으로 처리한다.

**무기칸 프리셋**

| 코드 | 크기 | 칸 | 넣을 수 있는 예 | 바바 | 팔라 | 아마 | 네크 | 소서 |
|---|---|---|---|---|---|---|---|---|
| W3 | 1×3 | 3 | 한손 무기 1 | 5% | 10% | 10% | 15% | 15% |
| W4 | 2×2 | 4 | 단검+완드, 완드+보주, 소형 방패 | 5% | 5% | 5% | 25% | 30% |
| W6 | 2×3 | 6 | 2×3 양손, 한손+카이트 방패, 한손+한손 | 30% | 45% | 45% | 40% | 40% |
| W8 | 2×4 | 8 | 2×4 양손, 한손+한손+단검, 2×3+보조 1×… | 40% | 30% | 35% | 20% | 15% |
| W12 | 3×4 | 12 | 2×4 양손 + 한손 + 여유, 대형 방패 + 한손 | 20% | 10% | 5% | 0% | 0% |

**장신구칸 프리셋**: A6 (2×3), A8 (2×4), A9 (3×3), A10 (2×5), A12 (3×4). 직업 무관 균등이되 W12를 받은 용사는 A6/A8만 나온다.

**방어구칸**: `합계 − 무기 − 장신구`를 아래 표에서 고른다. 총 40 기준 예: (W3, A12, R25=5×5), (W6, A10, R24=4×6), (W8, A12, R20=4×5), (W12, A8, R20=4×5), (W4, A12, R24=4×6), (W6, A9, R25=5×5). 방어구칸 허용 크기: 4×4(16), 3×6(18), 4×5(20), 3×7(21), 4×6(24), 5×5(25). 합이 맞지 않으면 장신구칸 프리셋을 한 단계 조정한다.

방어구 5부위를 다 넣으면 6+4+4+4+2 = 20칸이므로 20칸 방어구칸은 딱 맞고, 16칸은 한 부위를 포기해야 하며, 24~25칸은 부적을 못 넣는 대신(부적은 장신구칸) 여유가 남아 회전 배치가 자유롭다. → 방어구칸이 작은 용사는 대신 무기칸이나 장신구칸이 크다는 것이 개성이다.

### 9.2 손 규칙 (무기칸)

- 용사는 손이 2개다. 한손 무기 = 1, 양손 무기 = 2, 보조(방패·보주·해골 방패) = 1.
- 기본: **무기 최대 1개 + 보조 최대 1개**, 손 합계 ≤ 2.
- **바바리안**: 한손 무기 2개 동시 활성(쌍수). 손 합계 ≤ 2는 동일하므로 양손+한손은 불가.
- 3차 전직 **전쟁광**(바바리안): 쌍수 시 두 번째 무기 공격력 100% 적용(기본 쌍수는 두 번째 무기 60%).
- 3차 전직 **성역 수호자**(팔라딘): 대형 방패(2×3)를 들어도 move 페널티 없음.
- 무기칸에 여러 개를 넣으면 **먼저 놓은 순서**로 활성 판정하고 손이 모자라면 나머지는 비활성. 용사는 비활성 무기를 "예비 무기"로 들고 다니는 셈이며, 활성 무기가 분해·이동되면 다음 것이 자동 활성된다.
- 직업 제한 무기는 놓을 수는 있지만 비활성이다(운반용). 레벨 제한도 같다.

### 9.3 부위·종류 규칙

- 방어구: 부위당 활성 1개. 같은 부위 두 번째부터 비활성.
- 장신구: 반지 활성 2, 목걸이 1, 토템 1, 부적 무제한.
- 회전: 모든 아이템은 90° 회전 가능(1×3 ↔ 3×1). 스프라이트는 회전해서 그린다. 1단계 구현에서는 회전을 제외해도 된다.

### 9.4 조작

- 마을 창고 ↔ 장비창 드래그. 창고에서 끌어오면 초록(가능)/빨강(불가) 미리보기. 놓으면 즉시 효과 적용, 프로필 능력치 델타(+12 공격력 등) 1초간 표시.
- **자동 배치** 버튼: 현재 창고에서 이 용사가 쓸 수 있는 아이템 중 능력치 합(`powerOf` 기준)이 가장 높아지도록 탐욕 배치. 격자 게임을 원치 않는 플레이어용 안전장치.
- 아이템 위에 박음돌을 드롭하면 빈 홈에 삽입. 삽입은 영구(제작대 "홈 비우기" 조합으로 박음돌 파괴·회수 선택).
- 우클릭/길게 누르기: 창고로 보내기. 더블클릭: 다른 용사에게 보내기 메뉴.
- 격자 위 툴팁: 이름(등급색), 베이스·단계, 크기·무게, 활성/비활성 사유, 접사, 홈 상태, 세트 진행(2/4), 진언 문구.

### 9.5 첫 배치 = 구매

기존 경제 규칙 유지. 창고의 `purchased: false` 아이템을 처음 어떤 용사의 장비창에 놓을 때 그 용사의 골드에서 가격을 빼 운영금에 더한다. 가격은 `베이스 기본가 × 등급 배수(일반1 / 매직2.2 / 레어4.5 / 세트7 / 유니크9) × (1 + 접사 단계 합 × 0.08) × (1 + 용사 price%)`. 골드가 모자라면 놓을 수 없다(빨강 미리보기 + 사유). 이미 구매한 아이템은 용사 간 이동 무료. 분해는 창고에서만 가능(장비창에 있으면 먼저 빼야 함).

## 10. 무게

- 용사 **무게 용량** = 직업 기본 + 레벨 × 1 + `str`. 직업 기본: 바바리안 100, 팔라딘 85, 아마존 70, 네크로맨서 55, 소서리스 50.
- 장비창에 놓인 **모든** 아이템(비활성 포함)의 무게 합이 적재량이다.
- 적재율 ≤ 100%: 없음. 100~120%: 이동·공격 속도 -10%. 120~150%: -25%, 재생 0. 150% 초과: **놓을 수 없음**(빨강). 노새의 허리띠 등은 페널티 절반.
- 무게는 베이스와 단계에 따라 정해지고(2단 +20%, 3단 +40%), 앞말 `가벼운`(무게 -30%, 무기·방어구, T1 ilvl 10)이 존재한다. 정교 품질은 무게 -10%.
- 의도: 판금 갑주+대형 방패+양손 도끼 풀 세팅은 바바리안/팔라딘만 가능하고, 소서리스는 로브+보주+완드 경량 구성으로 유도한다. 힘 접사가 소서리스에게도 가치가 생긴다.

## 11. 마을 창고

- 창고 건물 레벨(신규 `upgrades.warehouse` 0~5)로 크기 결정: 10×8(80) → 10×10 → 10×12 → 12×12 → 12×14 → 12×16(192). 기존 120개 재고 상한은 폐지.
- 박음돌(보석·각인석·보옥)과 재료는 창고의 **박음돌 서랍**(격자 아님, 종류별 스택, 스택 상한 99)에 따로 보관한다. 격자 관리 부담을 줄이기 위해 아이템 격자에는 장비만 들어간다.
- 창고 격자가 가득 차면 귀환한 용사의 전리품은 **하역장**(임시 목록, 20개)에 쌓이고, 초과분은 자동 분해된다(설정에서 "일반 자동 분해", "매직 자동 분해" 필터 제공).
- 필터·정렬: 등급, 종류, 직업 사용 가능, 홈 있음, 세트, "이 용사가 놓을 수 있음". 정렬 시 격자를 재배치한다(창고는 템트리스 대상이 아니므로 자동 정리 허용).
- 도감(세트·유니크·진언) 탭은 창고 화면에 붙인다.

## 12. 홈 · 박음돌 · 진언

### 12.1 홈

- 베이스 크기별 홈 최대: 1×1→0, 2×1→1, 1×2→2, 2×2→2(관 3), 1×3→3, 2×3→4(판금 4), 2×4→6.
- 드롭 시 홈 개수: 일반 25% 확률로 1~최대(작은 수가 흔함). 매직·레어 15% 확률로 1~2. 세트/유니크는 정의값.
- 제작대 조합 **홈 뚫기**: 일반 아이템 + 마력석 10 + 철 20 → 1~최대 홈 무작위(이미 홈이 있으면 실패). 매직/레어 + 영혼 결정 5 → 홈 1개(최대 2).
- 홈에 넣을 수 있는 것: 보석·각인석·보옥. 삽입 후 회수는 제작대 **홈 비우기**(아이템 유지, 박음돌 파괴) 또는 **박음돌 회수**(박음돌 유지, 아이템 파괴).

### 12.4 진언

| 불멸의 증표 | 방어구 4홈 (몸) | 진 · 모르 · 루스 · 웬 | defPct 80%, resAll 20%, regen 8, 체력 30% 이하 dr +15% | 후반 갑옷 |
| 별의 인도 | 투구 3홈 (관) | 자르 · 헤스 · 진 | 모든 스킬 +2, find 40%, cooldown 8% | 후반 투구 |
| 심연의 부름 | 무기 5홈 | 카르 · 그림 · 감 · 파르 · 아스트 | atkPct 150%, 적 방어 -30%, crit 15%, 치명타 피해 +50% | 심연 물리 |
| 별의 노래 | 무기 5홈 (마법 무기) | 자르 · 웬 · 케른 · 온 · 이센 | spell 120%, 모든 스킬 +3, cooldown 20% | 심연 마법 |
| 끝없는 여정 | 방어구 5홈 | 크룸 · 세드 · 자르 · 진 · 온 | move 30%, 모든 스킬 +2, 사냥 지속 시간 무제한(자동 귀환 기준 완화) | 심연 방어구 |

진언 레시피는 처음엔 숨김이며 도감에서 "발견"으로 열린다. 발견 방법: (1) 우연히 맞춰 완성, (2) 심연 층 보상 상자에서 **진언 조각 문서** 드롭(레시피 공개), (3) 마트 게시판 의뢰 보상. 미발견 진언도 조건을 맞추면 완성된다(원작과 동일한 재미).

### 12.5 보옥

무작위 접사 1~3개(매직 1~2, 레어 3)를 가진 1×1 박음돌. 홈에 박으면 접사가 그대로 아이템에 더해진다. 진언 홈에는 쓸 수 없다. 레어 보옥 이름은 레어 이름표에서 "○○ 눈물/인장" 형태로 붙인다.

## 13. 획득 경로

1. **드롭**: 몬스터 처치 시 `기본 드롭률 30% × 정예 5배 × (1 + find)`로 아이템 1개(정예 1~3개). 드롭은 처치 기여 용사의 임시 가방에 들어가고 귀환 시 창고에 입고된다(기존 재료 입고와 동일 경로). 임시 가방은 아이템 6개 상한(`carry`로 증가). 가득 차면 등급 낮은 것을 버린다.
2. **제작(대장간)**: 기존 `craft` 대체. 재료로 **베이스를 고르고** 등급을 고른다. 일반: 철 8. 매직: 철 16 + 마력석 3(접사 무작위). 레어: 철 28 + 마력석 10 + 영혼 결정 2(접사 3~4개 무작위). ilvl = 대장간 레벨 × 12 + 최고 용사 레벨 × 0.5. 세트·유니크·진언 아이템은 제작 불가(드롭·조합 전용).
3. **제작대 조합** (대장간 레벨 2 이상):
   - 각인석 합성(12.3), 보석 합성(12.2), 홈 뚫기, 홈 비우기/회수(12.1).
   - **재련**: 매직 아이템 + 완전 보석 1 → 접사 재굴림(ilvl 유지). 레어 + 영혼 결정 10 + 완전 보석 1 → 접사 재굴림.
   - **승급**: 일반 → 매직(마력석 5), 매직 → 레어(정제 보석 3 + 마력석 20). 등급을 올리며 접사 새로 굴림.
   - **단계 올리기**: 1단 유니크/세트 + 영혼 결정 30 + 완전 보석 2 → 2단 베이스로 승급(고정 옵션 유지, implicit 상승). 2단→3단은 영혼 결정 80 + 완전 보석 3 + 금 각인석 1.
   - **반지·목걸이 도박**: 매직 반지 3 → 무작위 반지(레어 10%, 유니크 1%). 목걸이 동일.
   - **세트 조각 교환**: 같은 세트 부위 2개 + 영혼 결정 20 → 그 세트의 다른 무작위 부위.
4. **떠돌이 상인**: 게임 시간 하루에 한 번 마을 게시판 옆에 등장(2분). 운영금으로 **미감정 아이템** 5개 판매(가격만 보고 등급 미공개, 감정 시 확률 매직 55 / 레어 35 / 세트 5 / 유니크 5%). 원작 도박 대응. 심연 층이 열리면 각인석도 판다.
5. **게시판 의뢰**: "액트 III 정예 10마리 처치" 같은 의뢰 보상으로 지정 등급 아이템·각인석·진언 조각 문서.

## 14. 출처 레벨과 무한 스케일 (심연 층)

- 몬스터 레벨: 액트 I 1~8, II 8~20, III 20~35, IV 35~50. 정예 +3, 보스 +5.
- `ilvl = 몬스터 레벨 + 정예 보너스`. 제작은 13장 규칙. 접사 단계·베이스 단계·세트·유니크 후보는 전부 ilvl로 잠긴다.
- **심연 층**: 액트 IV의 봉인문(기존 POI)이 용사 한 명 Lv.50 도달 시 열린다. 층 N의 몬스터 레벨 = 50 + 2N, hp·atk는 층당 +12%(복리), 드롭 수량 +3%/층, 세트·유니크 확률 +0.1%p/층(상한 층 50). 층은 배정한 용사들이 층 보스를 잡으면 다음 층이 열리고, 플레이어가 원하는 층으로 되돌아가 배정할 수 있다. 층마다 **보상 상자** 1개(각인석·진언 조각 문서·보옥 확정 1 + 아이템 2).
- 용사 레벨 상한을 60 → **99**로 올리고 61 이후 필요 경험치를 가파르게(층 진행과 보조). 스킬 포인트는 Lv.60까지만 지급하고, 61+는 **심연 각인**(레벨당 str +1, 모든 저항 +0.5%)로 대체해 밸런스를 단순화한다.
- 무한 요소 정리: 심연 층(수치) × T7/T8 접사(ilvl 60/80) × 3단 베이스 × 별 계열 각인석(심연 10+) × 6홈 진언 × 도감(세트 9·유니크 24·진언 20 = 초기 53항목, 콘텐츠 추가 시 데이터만 늘림) × 20명 용사 각자의 격자 형태.

## 15. 저장 구조와 마이그레이션 (version 2 → 3)

새 상태:

```js
s.version = 3
s.warehouse = { w: 10, h: 8, items: [{ id, x, y }] }      // 격자 배치
s.dock = [id, ...]                                          // 하역장
s.drawer = { gems: { 'ruby:3': 2 }, runes: { ar: 5 }, jewels: [item...] }
s.items = { [id]: item }                                    // 인스턴스 사전 (창고·장비창·하역장·가방 공통)
s.codex = { sets: {}, uniques: {}, mantras: {} }
s.upgrades.warehouse = 0
s.abyss = { floor: 0, best: 0 }
hero.grid = { weapon: { w, h }, armor: { w, h }, accessory: { w, h } }
hero.placed = [{ id, zone, x, y, rotated }]
hero.bagItems = [id, ...]
```

`hero.equipment`와 `s.inventory` 배열은 제거하고 아래 규칙으로 변환한다.

1. 기존 `inventory` 항목 → 새 인스턴스. `slot: weapon` → 직업 기본 베이스(바바 `axe2h`, 네크 `wand`, 아마 `shortbow`, 소서 `staff`, 팔라 `hammer2h`), `armor` → rarity에 따라 `leather/chain/chain/plate`, `accessory` → `amulet`. 기존 `stats`를 그대로 `implicit`에 넣어 **능력치를 보존**한다(접사는 없음, `nameParts.fixed`에 옛 이름). rarity 0/1/2 → 일반/매직/레어 색, 3(전설) → 유니크 색 + 이름 앞에 "옛 시대의". `purchased` 유지. ilvl = 10 × (rarity + 1).
2. 각 용사의 `grid`를 프리셋에서 뽑되, **장착 중이던 무기가 들어가는 무기칸**을 보장(바바·팔라 2×4 이상, 소서·네크 2×3 이상, 아마 2×3 이상). 장착 중 3개를 자동 배치하고, 배치가 실패하면 창고로 보낸다.
3. 남은 `inventory`를 창고 격자에 순서대로 채우고 넘치면 하역장에 넣는다(하역장 상한 없이 마이그레이션 1회만 허용).
4. `materials`·골드·운영금·레벨·전직·스킬·마을 배치는 그대로. `restore`의 검증 규칙(격자 겹침 없음, zone 범위, 존재하는 id, 활성 규칙은 재계산이므로 검증 불필요)을 갱신한다.
5. version 3 저장을 구버전 코드가 읽으면 거부한다(기존 "미래 revision 거부"와 동일).

## 19. 열어 둔 결정 (사용자 확인 필요)

- 용사 등급 표기를 ★로 바꿀지(장비 등급 매직/레어와 이름 충돌 회피).
- 회전 허용 여부(허용 시 템트리스 자유도↑, 격자 형태의 개성↓). 이 문서는 허용을 기본으로 둔다.
- 미감정 시스템을 떠돌이 상인 전용으로 둘지, 드롭에도 적용할지(드롭에도 적용하면 "감정" 클릭이 늘어남). 이 문서는 상인 전용을 기본으로 둔다.
- 창고 격자를 템트리스 대상으로 둘지(현재 설계: 자동 정리 허용, 격자 게임은 용사 장비창에서만).
- 레벨 상한 99 확장 시점(4단계 이전에 올리면 심연 없이도 스킬 밸런스가 흔들림).
